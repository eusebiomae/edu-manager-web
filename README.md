Sistema ERP moderno desenvolvido para estudo e demonstração de uma arquitetura Full Stack utilizando **Next.js**, **React**, **TypeScript**, **Tailwind CSS** e **ASP.NET Core Web API**.

Este projeto simula um sistema de gestão escolar, seguindo padrões utilizados em projetos corporativos, com foco em escalabilidade, organização do código e boas práticas de desenvolvimento.

# ▶️ Como executar

Clone o projeto

```bash
git clone https://github.com/SEU-USUARIO/edu-manager-web.git
```

Entre na pasta

```bash
cd edu-manager-web
```

Instale as dependências

```bash
npm install
```

Execute

```bash
npm run dev
```

Abra

```
http://localhost:3000
```

---

# ⚙️ Variáveis de Ambiente
